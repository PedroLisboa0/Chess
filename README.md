# Chess Application in Python #

This is a chess game made using python and pygame. The inspiration for this project was [this video by Sebastian Lague](https://www.youtube.com/watch?v=U4ogK0MIzqk&t=11s), but i used the minimun amount of
research during the development to maximize the learning i could have by trying things my way.
